Pill-shaped action button; primary (Celeste cielo) is the one main action per screen.
```jsx
<Button size="lg" iconRight="arrow-right">Comenzar ejercicio</Button>
<Button variant="secondary">Ver pista</Button>
```
Variants: primary, secondary (white + 2px ink outline), ghost, dark (ink). Sizes sm 36 / md 44 / lg 56. Press = scale .97. Never coral or green buttons.
